# 大盘强弱日级数据原型

**性质：场外观察 / 研究工具。绝不进入 CAN SLIM V1.1 执行层。**
M 门仍是唯一执行裁决；本原型只输出观察状态，**不定义场景标签、不做综合分数、
不做加权打分**；不给个股买卖建议、不预测股价。

本原型同时是一套**有效性跟踪参考模型**：每日把三路指标状态与当日 M 门状态
并排记入对照日志（`data/comparison_log.csv`），两周试跑结束时（约 12-04）
检查指标是否独立于 M 门提供信息；未证实有效的不升级为信号。
场景标签（低位修复 / 高位防守 / 定价背离 / 无主导场景）不在本期定义，
等试跑后从观测分布里再定。

## 三路指标

### 1. 期指基差（中金所，IF/IH/IC/IM 主力合约）

- 取数：中金所官网日统计 CSV（`fetch_basis.py`），主力 = 同品种持仓量最大者；
  现货指数收盘价取腾讯 `qt.gtimg.cn`（沪深300 / 上证50 / 中证500 / 中证1000）。
- 公式：基差 = F − S（F 为当日**结算价**）；基差率 = (F−S)/S；
  **年化基差率 = 基差率 × 250 / 剩余交易日**（2026-11-19 统一口径：
  原 ×365/剩余天数改为 ×250/剩余交易日，国内期货基差年化常用口径；
  原型尚未积累历史，改动不影响历史一致性）。
  剩余交易日 = 自次一交易日起至交割日（含交割日）的交易日数；
  交割日 = 交割月第 3 个周五。2612 合约交割日 2026-12-18，
  2026-11-20 起剩余 20 个交易日。
- 5 日变化方向：年化基差率绝对值缩小为收敛、扩大为扩大。
- 标注：交割周（剩余 ≤5 日）基差机械收敛、年化值不可靠；
  主力换月时标注跳变；5–7 月分红季未做分红调整、置信度下降。
  A 股持续贴水是常态：**只看年化基差率的历史分位，不看绝对值**。
- 基差缺失时输出“无信号”，禁止用 ETF 折溢价顶替。

### 2. 前 20 结算会员持仓（中金所）

- 取数：中金所官网成交持仓排名 CSV（`fetch_members.py`），IF/IH/IC/IM 各一份。
- 多空净持仓 = 持买单量前 20 合计 − 持卖单量前 20 合计；另记日变化。
- 口径：**代客口径**——结算会员汇总了客户与自营，单家会员的翻转不等于市场转向；
  前 20 名合计 ≠ 全市场持仓。
- 成交量排名表本身**无买/卖拆分**（每家只有一列成交量），不编造拆分数字。
- 已知口径差异（2026-11-20 实测）：排名表成交量前 20 合计约为日统计合约成交量的
  1.5 倍（IF 1.56、IH 1.59、IC 1.55、IM 1.49），页面未说明换算关系；
  疑为同一笔成交在买卖双方会员处双边计数，此处仅并列记录、不作调和，
  脚本输出两者比值供核对。

### 3. 日级 TRIN（东财全市场快照）

- 取数：东财 `push2.eastmoney.com/api/qt/clist/get`（`fetch_trin.py`），
  全 A 股约 5565 只，每页 100 条，顺序分页拉取并加重试。
  **必须按 fid=f12（代码）排序**：按 fid=f3（实时涨跌幅）拉取时价格在分页间变动，
  行会跨页重复/丢失（2026-11-20 实测：5565 行仅 5123 个唯一代码）。
- 公式：TRIN(量) = (上涨家数/下跌家数) / (上涨成交量/下跌成交量)；
  TRIN(额) = (上涨家数/下跌家数) / (上涨成交额/下跌成交额)；
  **两口径分歧时以成交额口径为准**（主读数 = 成交额口径）。
  另算 10 日均值（从积累日起，首周窗口不足要标注）。
- 涨跌停家数按板块阈值计：创业板 300/301 与科创板 688 为 20%（ST 亦然）、
  主板 ST 为 5%、其余主板 10%（阈值减 0.1 个百分点容忍价格取整）。
  旧口径 f3≥9.9 一刀切会把创业/科创 10%–20% 的涨跌计入涨跌停，
  2026-11-20 实测会多计约百只，不可用。
  A 股涨跌停会扭曲读数，标注当日涨跌停家数作参考；
  **不套用美股 0.5/2.0 阈值**，阈值以后拿 A 股自己的历史分布定。
  极端提示仅在滚动分位 <5% 或 >95% 时输出，其余静默。
- 样本检查：上涨+下跌家数与（全 A 总数−停牌数）偏差 >5% 时跳过本轮并标记样本异常。

## 通用规则（数据自检与落盘）

- 落盘字段：每行含 `timestamp`、`indicator`、`value`、`percentile`、
  `data_quality_flag`（另有各路明细字段）。
- 分位最小有效天数：100 日分位需 ≥80 个有效日、250 日分位需 ≥200 个有效日，
  否则该分位记 null 并标注“分位仅供参考”。
- 自检：原始价格以双源交叉核对（东财 vs 腾讯）为主；3σ 检查只用于日收益率与
  基差率本身，只标记、不自动跳过；接口失败切换备用源，仍失败输出“无信号”，
  不得用旧数据冒充当日数据。
- 失败不覆盖旧文件：当日数据未发布或拉不全时不写文件。

## 历史窗口（实测说明）

- 原型上线日 **2026-11-20**，三路历史均从当日开始积累，**有效历史 0 日**；
  100 日 / 250 日分位、TRIN 10 日均值（n=1）、基差 5 日变化、净持仓日变化
  在首日均为 null 或窗口不足，属预期状态，不代表数据缺失。
- 未拿到中金所 1 年回溯历史：中金所日统计 / 排名 CSV 按日期分文件存放，
  理论上可逐日回拉补历史；本次任务只验证了当日取数，未做批量回溯
  （回溯脚本待试跑期间按需补充：`--date` 已支持逐日补算）。
- 分位窗口实际长度：上线后每日 +1 个有效日；100 日分位在积累满 80 日后
  首次出数（约 2027-03 中旬），250 日分位在 200 日后（约 2027-09）。
  在此之前分位一律记 null。

## 如何跑

本地（Python 3 + `requests`，无需 pandas）：

```bash
cd ~/workspace/market-strength
python3 fetch_basis.py     # 期指基差（收盘后，中金所数据约 17:00 发布）
python3 fetch_members.py   # 前 20 会员持仓
python3 fetch_trin.py      # TRIN
python3 summarize.py       # 当日小表 + 对照日志（读当日 16:16 扫描日志取 M 门）
```

- 补算过去某日：`python3 fetch_basis.py --date 2026-11-21`（同日行会被替换）；
  `--csv` / `--csv-dir` 可用本地已下载的中金所 CSV 跑（验证用）。
- 自检（不联网）：`python3 fetch_basis.py --selftest` 等。
- 收盘保护：15:05 前不计算（防盘中误触发）；`--date` 不受此限。

GitHub Actions（文件已备好，未推送）：`.github/workflows/daily-market-strength.yml`
每日 17:30 北京时间（09:30 UTC，周一至周五）运行三路脚本 + 汇总并提交
`market-strength/data/*`。注意：Actions 环境内无当日 16:16 扫描日志，
汇总时 M 门记“未取到（扫描日志缺失）”；本地跑 `summarize.py --date <当日>`
会以同日去重方式把 M 门补进对照日志同一行。

## 季度层国家队持仓快照（本次不做抓取脚本，只定口径）

- 季末快照，季度内调仓不可见；季报十大流通股东，滞后约 1 个月；
- 退出前十大 ≠ 清仓；汇金主战场在 ETF 持有人名单（基金季报），
  不在个股十大股东；户名须精确匹配；汇金 8 只国有股权单列剔除。
- 汇金/证金持仓变化是季频慢变量，不拼进日频表。
