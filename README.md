# A股交易首页（手机版）

纯静态单文件手机看板：`index.html`，零外部 JS 依赖，可直接用 GitHub Pages 打开。

## 功能
- 大盘指数卡：上证 / 深证成指 / 创业板指 / 科创50
- 重点观察股表（15 只预置：AI 硬件、光模块、半导体设备、机器人）+ 自选增删（localStorage 持久化）
- 手动刷新行情
- 市场模式（进攻 / 谨慎 / 防守）+ 交易检查卡 + 快速仓位计算 + 执行纪律

## 行情来源
腾讯财经公开行情接口（`qt.gtimg.cn`），浏览器端 JSONP 直连，无需 key。
非官方接口，可能延迟、限流或不可用；失败时页面报错、不编造数据。下单前请以券商软件核对。

## 部署
本仓库通过 GitHub Pages 发布：Settings → Pages → Deploy from a branch → `main`。
手机 Chrome 打开 Pages 网址 → 菜单 →"添加到主屏幕"。

## 说明
- 不自动交易、不给买卖建议、不预测价格。
- 后续计划：按 V1.1 交易体系扩展（M 门状态、A/B/C 档信号）。
